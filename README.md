# Jews_project_file_merge_PCA
Скрипт для объединения vcf.gz файлов с общим vcf.gz файлом с образцами по еврейским популяцисм, построения графиков PCA и определения принадлежности новых образцов к популяциям согласно PCA. Полученные файлы сохраняются в папку output (создается внутри папки с vcf.gz файлами) <br>
<br>
- скрипт нормализует (данные по нормализации сохраняет в normalization_stats.tsv), индексирует и объединяет отдельные vcf.gz файлы с общим vcf.gz файлом по еврейским популяциям (vcf_jews_bgz.vcf.gz);  <br>
- из общего vcf.gz файла удаляется один родственный образец (nx1575, он уже известен ранее - единственная пара образцов с PI-HAT>0.25: PI_HAT=0.5386 между образцами nx1575 и kl9502), проверка на родственность не проводится в данном скрипте;  <br>
- проводится фильтрация общего vcf (из входного VCF-файла удаляются все вставки и делеции (оставляются только однонуклеотидные полиморфизмы, SNP). Сохраняются только варианты, у которых частота минорной аллели (MAF) не ниже 5%. Оставляются только варианты, для которых данные присутствуют как минимум у 90% образцов;
- LD-pruning (выполняется с использованием скользящего окна в 50 SNP, с шагом 10 SNP, при этом пары SNP с коэффициентом корреляции r² > 0.1 исключаются);
- PCA выполняется при помощи plink;
- создается Python-скрипт, который загружает результаты PCA, сопоставляет образцы с группами из таблицы jews_and_new_groups.csv (ID новых образцов добавляются в таблицу, группа - new); <br>
- строится PCA-график PC1–PC2 и PCA-график PC1–PC3 с эллипсами для известных популяций (для графика PC1-PC3), на графике обозначаются ID новых образцов; <br>
- cоздается таблица (samples_in_ellipses.csv) с данными о попадании образцов в эллипсы. Новые образцы обозначаются, как new. Если новый образец не попал в эллипс, он обозначается, как not_defined; <br>
- графики PCA сохраняются в формате pdf (PCA_PC1_PC2.pdf, PCA_PC1_PC3_with_ellipses.pdf).

**Программы, которые используются при выполнении скрипта: <br>**
- bcftools 1.20
- VCFtools (0.1.17)
- PLINK v1.9.0-b.7.7 64-bit (22 Oct 2024)            cog-genomics.org/plink/1.9/
- Python 3.10.10 (библиотеки pandas, numpy, matplotlib, seaborn, scipy)
  <br>
**Запуск скрипта:** merge_script_jews.sh ~/absolute/path (абсолютный путь к папке с vcf файлами, которые нужно объединить) <br>
 <br>
В папке находятся: <br>
- vcf файлы, которые нужно объединить <br>
- общий vcf файл по популяциям (vcf_jews_bgz.vcf.gz)  <br>
- таблица (jews_and_new_groups.csv) с обозначениями ID и групп еврейских популяций из общего файла vcf_jews_bgz.vcf.gz  <br>

**После выполнения скрипта в папке output (будет создана в папке с образцами) будут находиться файлы:** <br>
- объединенный файл со всеми образцами с индексацией - merged.vcf.gz и merged.vcf.gz.csi
- файл, который использовался для LD-pruning и PCA после фильтрации и удаления родственного образца - filtered_no_nx1575.vcf.gz
- файлы после LD-pruning - pruned.prune.in, pruned.prune.out, pruned.log
- файлы для PCA - pruned.bed, pruned.bim, pruned.fam, pruned.nosex
- файлы после PCA - pruned.eigenval, pruned.eigenvec
- таблица с данными при нормализации vcf файлов (Sample, Total, Split, Joined, Realigned,	Skipped) -  normalization_stats.tsv
- обновленная таблица с ID новых образцов (группа - new) - jews_and_new_groups.csv
- таблица с обозначениями принадлежности новых образцов к популяциям (согласно эллипсам по графику PCA) - samples_in_ellipses.csv
- графики PCA - PCA_PC1_PC2.pdf, PCA_PC1_PC3_with_ellipses.pdf
